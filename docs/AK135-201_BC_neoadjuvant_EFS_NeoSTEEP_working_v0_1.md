# AK135-201 BC新辅助治疗人群EFS：NeoSTEEP 2023独立统计定义工作稿 v0.1

**日期：** 2026-10-13  
**历史版本，已被[用户确认的v0.2 EFS工作稿](./AK135-201_BC_neoadjuvant_EFS_NeoSTEEP_confirmed_v0_2.md)取代。** 2026-10-13用户明确选择**A / KEYNOTE-522型：术前局部/区域进展只有导致不能根治性手术时才为EFS事件**，排除本v0.1曾推荐的“进展而需额外/更换非方案治疗也计EFS”的B规则。本文件的A/B对照及B版方案拟稿**仅为历史决策过程，不得当作现行已确认正文**。BC术后辅助IDFS已确认，原CP Word未修改。

## 1. 任务与直接文献

本轮沿用用户明确流程：**不检查或复制AK135-201原方案EFS模板**，依据原始乳腺癌新辅助终点共识及代表性随机试验，先自主形成可执行统计口径。

- **NeoSTEEP，Litton JK et al.**, *J Clin Oncol* 2023;41:4433–4442, DOI 10.1200/JCO.23.00435，[原刊完整文本](https://ascopubs.org/doi/10.1200/JCO.23.00435)，[原刊PDF Table 3可直接检索](https://ascopubs.org/doi/pdfdirect/10.1200/JCO.23.00435?role=tab)，[PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC10522109/)：新辅助**EFS从random assignment开始**，既包括手术前远处进展及满足预先规定条件的局部区域进展，也包括手术后与STEEP 2.0 IDFS一致的侵袭性复发/第二原发侵袭性非乳腺癌/死亡。**BC-EFS与EFS区别为不包括非乳腺第二原发侵袭性癌**，分别与辅助IDFS/IBCFS对应。
- **KEYNOTE-522**, Schmid P et al., *N Engl J Med* 2022;386:556–567, DOI 10.1056/NEJMoa2112651，[PubMed原始摘要](https://pubmed.ncbi.nlm.nih.gov/35139274/)：新辅助化疗联合pembrolizumab/安慰剂的RCT，EFS定义为**随机化至因进展而无法根治性手术、局部/远处复发、第二原发癌或全因死亡**。这是较窄术前进展口径的可执行真实先例，并非AK135本身抗癌疗效依据。
- **NSABP B-59/GeparDouze**, *Nature Medicine* 2026，[原论文](https://www.nature.com/articles/s41591-026-04565-6)：宣称依NeoSTEEP，术前疾病进展若**导致需要非方案抗肿瘤治疗或变得无法手术**即记为EFS事件；术后侵袭性复发、对侧侵袭性癌、第二原发非乳腺恶性肿瘤和全因死亡亦为事件。这是术前事件定义稍宽、但仍具客观治疗后果的RCT先例。
- **BC辅助治疗IDFS已确认版本**：[STEEP 2.0 IDFS工作稿](./AK135-201_BC_adjuvant_DFS_STEEP2_working_v0_1.md)，同侧/区域/远处侵袭性复发、对侧侵袭性乳腺癌、**第二原发非乳腺侵袭性癌**及全因死亡为事件；排除单纯DCIS/LCIS、非侵袭性原位癌及STEEP原文排除的皮肤基底/鳞细胞癌。

**重要范围说明：** NeoSTEEP主要面向治疗癌症的新辅助临床试验，AK135是**预防CIPN的支持性药物**，EFS只做探索性抗肿瘤治疗潜在harm观察；**不能由引用NeoSTEEP自动要求本项目增加额外影像、设pCR主要终点、统计层级/alpha或延长随访**。

## 2. 终点选择与起算点

**推荐：EFS，而非BC-EFS**，因为BC术后辅助已确认采用含第二原发非乳腺侵袭性癌的**IDFS**；NeoSTEEP规定**术后EFS事件与IDFS一致**，而BC-EFS术后对应IBCFS。故EFS能让新辅助/辅助两类人群的**术后事件口径一致**。这是统计实施的连贯性，不是要求合并辅助IDFS与新辅助EFS分析。

**分析人群：** BC队列中接受**新辅助治疗路径**的随机受试者；是否按入组前**计划**的新辅助路径确定（不因后来手术取消/方案更改而转成辅助亚组），建议按随机前确定的治疗意图固定。与辅助IDFS分开描述。

**起算日期：** **随机化日期**，不是根治性手术日期。必须保留术前进展、死亡，不得作为术后IDFS把未手术者排除。

## 3. 事件与非事件矩阵

| 观察到的情景 | 推荐NeoSTEEP EFS处理 | 条件/备注 |
|---|---|---|
| **术前远处进展或出现转移性疾病** | **事件** | 经已有临床资料确认，按最早可确认进展日期 |
| **术前局部/区域进展** | **事件，需满足预先规定的临床进展规则** | 详见下文“唯一关键待定问题”；不是影像轻微增大一律计事件 |
| 根治手术后同侧侵袭性乳腺癌复发 | 事件 | 含胸壁、手术区域，按STEEP 2.0 IDFS |
| 手术后局部/区域侵袭性复发 | 事件 | 同术后IDFS |
| 手术后远处复发/转移 | 事件 | 同术后IDFS |
| **新发对侧侵袭性乳腺癌** | **事件** | 同STEEP 2.0 IDFS |
| **第二原发非乳腺侵袭性癌** | **事件** | 同IDFS；不包括皮肤基底/鳞状细胞癌及非侵袭性原位癌 |
| **任何原因死亡** | **事件** | 术前、术后均包括；无复发影像也仍是事件 |
| 术后病理非pCR/残留浸润性病变 | **不自动作为EFS事件** | 与新辅助抗肿瘤药物试验pCR终点分开，**不得把非pCR误判为EFS事件** |
| **非肿瘤进展原因未实施根治手术** | **不自动作为EFS事件** | 例如受试者拒绝、手术禁忌或一般医疗原因；按实际已有肿瘤/生存随访继续观察 |
| 单纯DCIS/LCIS、未证实的疑似进展 | 不作为EFS事件 | 按STEEP非侵袭性肿瘤事件范围及预定进展确认要求 |
| AK135暂停/停止、减量或停止化疗、治疗切换本身 | **不直接作为EFS事件或自动删失** | 如治疗更换**因已确认肿瘤进展**触发，则根据进展规则记录为事件；不得把因毒性而切换直接计为进展 |

**时序细节：** 治疗前方案决定新辅助，但患者随机后无法手术，**不能因未手术直接令其在随机日删失或当作事件**；要追踪其未手术的原因及已有资料中是否发生肿瘤进展/死亡。统计上手术日期是病程里界定术前/术后事件类型的节点，**不是EFS的起算日**。

## 4. 唯一主要待用户确认：术前局部/区域进展阈值

NeoSTEEP强调：**术前局部区域进展不一定导致不可切除**，故应预先指定用何类已有评估资料、什么进展标准作为事件。比较两个原始随机研究的实际口径：

**A. 较窄规则（KEYNOTE-522型）：**
- 术前局部区域进展且**因此无法进行根治性手术** → EFS事件；
- 若出现可核实局部区域进展，但仍能根治性手术 → 不单凭进展记录计EFS，继续观察其术后事件；
- 术前远处进展/转移单独为事件；
- **优点：** 与既定支持性CIPN研究随访贴合、操作简单、不需扩展常规影像进展评估门槛；**缺点：** 可能遗漏因进展改变治疗但最终仍能手术的肿瘤学不利信号。

**B. 加入进展导致额外抗癌治疗（NSABP B-59型）：**
- 术前局部/区域进展，**导致不可根治性手术，或因进展必须启动/更换非预先计划的抗肿瘤治疗** → EFS事件；
- 即使最终通过新增治疗成功手术，也应在**原先确证进展日期**计事件；
- 术前远处进展/转移单独为事件；
- **优点：** 比A更敏感地捕捉术前进展造成的实际临床不利后果；**缺点：** 需区分因**疾病进展** versus 因毒性/其他原因改方案，必须医学确认现有CRF/医疗记录能可靠判定。

**当前统计倾向：** 优先选**B**，因为AK135-201的EFS用于识别可能对背景抗肿瘤治疗造成的潜在干扰，发生确诊进展而需新增救援治疗即属于重要潜在harm信号；但**不把所有方案更改、未手术或常规残留病变一律记为EFS事件**。若医学现有随访无法稳定采集“进展导致额外抗癌治疗的因果原因”，A是更务实且KEYNOTE-522有直接先例的选择。**用户尚未选择，不能归档为已确定。**

两个选项都应在正式CP明确**“局部区域进展需要客观确认证据及医学认定”**，但不在本探索性II期为此增加超出既定SOC的影像访视。若已有诊疗进展标准能够客观确定，优先沿用已有临床资料，不额外发明新RECIST影像要求。

## 5. 原则性删失和分析方案

**事件日：** 术前进展取已有诊疗资料可核实的最早临床证据日期，而非后续方案切换或手术取消日期；术后复发/第二原发癌按最早可证实日期；死亡按死亡日期。不同资料判定证据优先级和同日并发事件需SAP定义。

**删失日：** 无事件者，取DCO前**最后能确认未发生所选EFS事件的已有疾病状态评估日期**；失访同理。随机后没有可用EFS疾病状态评估且无已知事件者可在随机日删失；**已知死亡不因缺少后续影像而忽略**。不因治疗停止/切换、未手术或非pCR本身自动删失。

**统计呈现：** 按原随机治疗组分别给N、EFS首事件n及类别、删失及随访时长，数据允许时KM描述，谨慎解释置信区间；无正式检验/alpha/新样本量、不据有限事件宣称安全性完全无潜在长期肿瘤学损害。由于研究中EFS极有可能因队列人数有限及12个月内实际随访不足而事件较少，建议优先**首事件类型和实际随访成熟度**，不承诺一定可报告可靠中位EFS或HR。

## 6. CP中文统计拟稿（以选项B为推荐草案，待用户确认）

> **乳腺癌新辅助治疗人群无事件生存期（EFS）**
>
> 对于乳腺癌队列中计划接受新辅助治疗的试验参与者，无事件生存期（Event-Free Survival，EFS）定义为自随机化日期至首次发生以下任一事件的时间，以先发生者为准：
>
> （1）根治性手术前出现疾病远处进展或转移；
>
> （2）根治性手术前出现经确认的局部或区域疾病进展，导致无法实施根治性手术，或者因疾病进展需要启动或更换预定方案以外的抗肿瘤治疗；
>
> （3）根治性手术后发生同侧乳房或胸壁侵袭性乳腺癌复发、局部区域侵袭性复发或远处复发/转移；
>
> （4）发生对侧侵袭性乳腺癌；
>
> （5）发生第二原发非乳腺侵袭性癌；
>
> （6）任何原因导致的死亡。
>
> 第二原发非乳腺侵袭性癌不包括皮肤基底细胞癌、鳞状细胞癌及非侵袭性原位癌。仅发现DCIS/LCIS、术后有残留侵袭性癌（未达到pCR）或非因疾病进展未完成根治性手术，均不自动构成EFS事件。试验用药或背景化疗提前停药、剂量调整或因非疾病进展原因更换治疗本身不作为EFS事件或自动删失原因。
>
> 疾病进展、复发或新发侵袭性癌的事件日期按最早可核实相应疾病证据日期确定，死亡按死亡日期。无EFS事件且随访终止或达到数据截止者，于末次可确认无EFS事件的疾病评估日期删失；无基线后相应资料且无已知事件者，在随机化日删失。
>
> EFS仅作为探索性肿瘤疾病结局，按随机治疗组描述EFS事件及删失人数、首次事件类型和随访情况。数据成熟时可采用Kaplan–Meier方法描述，不开展正式有效性假设检验，不因此增加额外肿瘤评估或随访要求。本研究不依据少量EFS事件推断AK135对原有抗肿瘤治疗无不利影响。

## 7. 待确认Comment及工作约束

- **C-BC-EFS-01（用户选择）：** 术前局部/区域进展采用**A**（仅进展使根治手术不可行）还是**B**（另纳入因确诊进展须新增/更换非预定抗肿瘤治疗）。推荐B；**不默认已批准**。
- **C-BC-EFS-02（医学/DM）：** 已有SOC资料和CRF能否区分明确局部区域进展、远处转移、进展导致无法手术、进展导致非预定治疗以及仅因毒性改变方案；不增加访视。
- **C-BC-EFS-03（统计/SAP）：** 明确实际首发疾病证据日期、随机前辅助/新辅助治疗意图的锁定、手术日状态节点、同日多事件、仅死亡/无postbaseline数据、随访成熟度与信息缺失。
- **C-BC-EFS-04（用户已确认的一致性）：** 已采用BC辅助**IDFS而非IBCFS**，新辅助推荐**EFS而非BC-EFS**，确保术后第二原发非乳腺侵袭性癌为两者共同事件；但依然对新辅助、辅助**独立分析、不合并风险集**。
