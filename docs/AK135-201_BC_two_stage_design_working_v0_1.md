# AK135-201 乳腺癌队列（BC）两阶段探索性统计设计（工作稿 v0.1）

**日期：** 2026-10-12  
**状态：** 历史疗效假设已找回；本次独立精确OC已计算；**BC最终每臂样本量、CP未来投射假设、Stage 1时点及最终promising阈值尚未获用户批准**。仅供CP讨论和统计方案选择，不得表述为已经定稿，也**未修改AK135-201方案原始Word**。

## 1. 来源与可追溯性

1. [cp_two_stage_framework.md](./cp_two_stage_framework.md)，2026-09-21，“Previous sample-size work”明确记录**BC安慰剂CTCAE≥2级CIPN事件率30%、AK135目标事件率20%或15%、对应绝对降低10或15个百分点**。这是先前假设的原始证据，**不是AK135已有预防疗效数据**。
2. [current_design_master_v2_4.md](./current_design_master_v2_4.md)及后续[AK135-201 CP review log](./AK135-201_protocol_review_decision_log.md)已固定**CRC专属**设计：三臂1:1:1、N=150、Stage1前60随机（覆盖旧版54）、CTCAE驱动、CP≥70%、项目级Go则两剂量均继续、最终描述性、无正式检验；不能把CRC pP45%/pT30%直接用于BC。
3. BC历史**具体最终样本量数字及原始计算表尚未在目前的仓库、上传CP或可检索历史对话中核实**。本次全新精确计算和精度反推在下文单独标注，**不称为历史BC样本量定案**。
4. 2026-10-12用户已确认：**BC随机前计划的神经毒性化疗方案是唯一随机分层因子**，层内1:1:1区组随机；具体分层类别待C-BC-14医学澄清真实背景药物方案后由统计确定。CRC不分层。
5. 实际主要有效性有**两个并列描述性终点**：EOT访视的18-item CIPN20评分较基线恶化≥10分，以及EOT访视CTCAE周围感觉或运动神经病变≥2级；**仅CTCAE用作本候选样本量与Stage1 CP设计**，不另给CIPN20配置检验/CP边界。

## 2. 核心设计与效应尺度

- 乳腺癌纳入按临床方案拟采用含神经毒性紫杉类的辅助/新辅助化疗人群，背景化疗方案和计划周期数在随机前记录；计划4–6个周期及Q3W/Q4W等存在异质性。具体方案化疗药物成分和5周期适用性尚留医学Comment。
- 三臂双盲随机、同时期安慰剂对照：AK135 12 mg/kg + 计划背景化疗、AK135 20 mg/kg + 计划背景化疗、安慰剂 + 计划背景化疗，1:1:1，**BC按随机前计划神经毒性化疗方案分层**。
- 二分类不良结局CTCAE≥2级CIPN的事件率分别为 pP、pL、pH；定义绝对风险差 Δj=pP−pj（正值有利）。基线方案分层是随机化设计，不意味着应改为四个独立主要比较组。
- **历史疗效情景：** 安慰剂pP=0.30；AK135 pT=0.15（目标降低15pp）或pT=0.20（目标降低10pp）。两个假设都需在当前EOT单点终点定义下由医学判断临床合理性，**不可把旧的“全程曾出现CIPN”发生率直接用于EOT当次事件率**。
- **建议校准主情景（非既定）：** (qP,qT)=(0.30,0.15)，把(0.30,0.20)作为较弱疗效情景/未来投射假设敏感性。q值是Stage1 CP的**未来结果投射假设**，不强制等于真实p值。
- **建议供OC筛选的最终临床开发信号定义（非既定）：** Δmax=max(ΔL-hat,ΔH-hat)；≥0.10记作“Go倾向”，[0.05,0.10)记作“Consider”，<0.05记作“No-Go倾向”。仅是描述性开发分类，不构成统计显著性、正式检验或成功上市证据。**最终这一10pp阈值是否适用于BC须明确批准，而不是因为CRC采用它就自动生效**。

## 3. 样本量候选如何得来

**历史数字未找到，只能重建精度参考。** 若仅要求两组观察风险差的Wald型95%区间**近似半宽**≤20pp，两个等组样本量估算为 n≈1.96²[pP(1−pP)+pT(1−pT)]/0.20²：BC 30%对15%给 n≈32.4，即至少**33/臂**；BC 30%对20%给 n≈35.5，即至少**36/臂**。这两个数字是**2026-10-12重新推算**、不含Stage1决策、缺失或分层因素，不能当成历史已选N，也不能当作正式确证性power论证。

考虑到本研究有**绑定Stage1 Go/No-Go**且必须保护“仅一剂量真正有效”的情景，不能只靠95%CI精度定N。精确binomial OC重新扫描 N=30、33、36、40、45、50、60/臂；重点报告N40、N50、N60。最终风险差阈值10pp对有限N呈离散台阶：N=40需安慰剂比至少一个治疗组多4个事件；N=45需5个；N=50需5个；N=60需6个。因而**N增加时OC不保证单调上升**，不能用连续正态近似掩盖事件计数台阶。

## 4. 候选Stage 1 Go/No-Go算法

本节**照搬CRC的逻辑结构，所有BC的数值均需独立审批**：

- 若以N50/臂作为工作候选，则Stage1按**前60名BC随机受试者**（40%）名义约20/臂；N40/臂则前48名、N60/臂则前72名。前述三组各自20、16、24仅是**名义均衡数**。BC按计划化疗方案分层随机，层间剩余不完整区组可能造成总组三臂人数不相等，**不得声称前60例必为20/20/20**，实际CP应按真实各臂人数。
- Stage1决策依据仅为已确认的**EOT当次CTCAE≥2级CIPN**。CIPN20同样作为主要描述性终点，但不另作为Stage1 Go阈值、不需要联合阳性。
- 按低剂量和高剂量分别计算 CP_L 与 CP_H。建议沿用CRC项目级规则：**M=max(CP_L,CP_H)；M≥0.70为BC队列Go，M<0.70为BC队列No-Go**（BC采用70%的适用性尚需用户确认）。
- 若BC Go，**两剂量及安慰剂均继续Stage2**；不因单一剂量CP低而单独淘汰剂量、不在期中重估样本量或改变分配比例。BC决策**独立于CRC队列**。
- **CP定义：** 对治疗组j，
  
  CP_j = P[(xP+YP)/(EP+FP) − (xj+Yj)/(Ej+Fj) ≥0.10 | Stage1数据,(qP,qT)]；
  
  R为该臂已随机且占用最终样本名额数，E为其EOT CTCAE确定结果人数，F=N−R为未来剩余名额。**已随机但结局indeterminate消耗名额、不假定其为事件/无事件，也不被未来入组者替换**；YP~Bin(FP,qP)，Yj~Bin(Fj,qT)。沿用CRC available-case + consumed-slot思想，具体缺失敏感性见既有统计设计记录。
- Stage1用于判断的成员必须按该队列**预定随机顺序**固定，不按EOT先成熟者重新选取；超过名义Stage1入组名额者属于pipeline，不进入该次Stage1 CP（但在项目允许的后续数据汇总中保留），无需统计重新设计由医学/临床已决定的进组成熟流程。
- 该BC分层随机下，每个计划化疗方案随机层均使用预随机类别锁定、保持盲态；具体类别和IWRS随机表、动态层容量与总组别平衡的影响，等医学澄清后独立模拟验证。

## 5. 本次精确Operating Characteristics（完整EOT、名义等组）

**算法：** 三臂随机结果与未来结果均分别服从对应binomial分布，完整枚举Stage1三组事件数以及Stage2事件数；投射假设qP=0.30、qT=0.15，Stage1按40%名义N、CP阈值70%、最终Δmax≥10pp。**这是2026-10-12全新精确枚举，不是历史已确认BC OC。** 假定所有受试者EOT结果可判定、三组Stage1及最终样本量完全相等，尚未结合BC分层随机/真实EOT缺失建模。

**敏感性：改未来投射假设而非改真实事件率**。若N50、Stage1名义每臂20、其他规则不变，但CP未来投射改成**qP=30%、qT=20%**，对真实“只有一剂量p=15%”情景，P(Stage1 Go)从**74.4%降至44.2%**，P(Stage1 Go且Final Go)从**64.8%降至41.5%**。对“仅一剂量p=20%”情景，P(Stage1 Go且Final Go)从**45.7%降至27.4%**。这表明BC的qT=15%还是20%**不能随意互换**，最终需要按照保护哪种临床效应来定。

**统计解释：**
- P(Stage1 Go)与P(Stage1 Go且Final Go)是两种不同指标；无binding中期停止的final-only概率不是完整两阶段设计的识别概率。
- null情景下19.7%是**达到探索性最终观察效应门槛的程序概率**，**不是正式一类错误率/显著性水平**。
- 候选N50/臂对单一15pp真实有效剂量的两阶段识别约64.8%；相比N40增加全队列30例，提高约4.9pp；相比N60节约30例，少约3.8pp。该取舍可作为选N时的定量依据，不是证明N50必然合理。
- 由于BC存在**背景化疗分层且EOT时间不一**，本版binomial模型不能量化分层内不同基线事件率、不同层入组比例、随机组人数不等、真实EOT缺失及早停造成的OC变化。**定案前必须补充按实际类别分布的随机化和结局成熟度敏感性分析**，避免把这里的等组理想OC称为最终运营性能。
- BC主要终点采用**EOT当次CTCAE**而非治疗期间任一次达到≥2；历史30%安慰剂率此前是样本量情景，尚未核实其是否匹配如今统一后的**EOT时点+4至6周期Q3W/Q4W混合**。必须将其临床合理性列为设计假设核查，而不是假定可无损沿用。
- 对探索性II期不设置正式有效性假设检验或α调整。真实BC在不同背景化疗下总体边际风险差的解释需呈现随机前计划化疗构成，可做按随机层的支持性描述；随机分层不等于多个独立主要终点或必须调整的正式检验。

## 6. 临时推荐与待用户决定

**当前推荐用于内部讨论：** N50/臂（总150）**作为一个可比于CRC但BC独立论证的候选**，Stage1 40%、CP≥70%、终末Δmax≥10pp，未来投射qP30%/qT15%，仅CTCAE驱动、两剂量全保留。**各数值不是BC已定案**；与N40、N60同列对照后选定。如医学把30%→20%的10pp效应定为必须重点保护的开发目标，则现有强效投射规则对该真实情景的两阶段识别仍仅45.7%（N50），不能继续把本提案说成能够充分保护10pp效应。

**最终待确定的最小关键事项：**
1. BC的**正式目标效应**是30%→15%（15pp），还是30%→20%（10pp）；历史记载两者均有，**没有已批准二选一**。
2. BC最终observed “Go倾向”≥10pp是否与CRC一致；该值是开发决策门槛而不是传统检验效应假设。
3. BC是否采用**N50/臂、40% Stage1、70%CP**组合；本版只是按CRC思路的示例选项，不从CRC已定规则推导成BC自动必须采用。
4. C-BC-14所需**允许背景神经毒性化疗及分层类别**，并评估每层预计比例；不同周期/方案EOT时点下安慰剂30%的合理性和取值范围。
5. BC分层IWRS后Stage1**真实人数偏差**、EOT缺失/indeterminate和pP/pT联合敏感性对OC的影响；计算方法可复用现有CRC code engine，但BC参数与真实随机算法必须另给。
6. 明确BC若作项目级No-Go，是**停止BC队列**还是影响全研究其他队列：按三队列相对独立的既定框架，此稿**建议仅作用于BC**，不能擅自停CRC/其他队列。

## 7. 待用于CP的研究专属工作文字（尚非最终方案）

**§11.3 队列2样本量与依据：**
> 乳腺癌队列拟按1:1:1分配至AK135 12 mg/kg、20 mg/kg及安慰剂组，并按随机前计划的神经毒性化疗方案进行分层随机。样本量采用探索性II期设计逻辑，以EOT时CTCAE≥2级CIPN发生比例作为设计校准依据。历史候选安慰剂发生率为30%，AK135目标发生率为15%或20%，分别相当于15或10个百分点的绝对降低。拟通过二项结局的Stage1与最终联合Operating Characteristics，结合预期临床开发价值、入组可行性和观察结果精度，确定最终每组及总体样本量。具体设计参数经确认后在正式方案中补充；EOT时CIPN20恶化≥10分为另一项并列主要描述性终点，但不单独据此设置Stage1统计边界或正式检验。

**§11.4 队列2阶段性决策（仅为拟稿，参数待审批）：**
> 乳腺癌队列拟设置独立的Stage 1有效性徒劳性评价，使用预先指定的首阶段随机人群，并仅依据EOT访视CTCAE≥2级CIPN终点，分别计算两个AK135剂量组相对安慰剂组的Conditional Power。若两个剂量组中至少一个达到预设的CP阈值，则队列2继续第二阶段且不进行剂量组淘汰；否则触发队列2的项目级No-Go。CP计算基于预设最终风险差开发信号门槛和未来事件率假设，对无法确定EOT结局但已占用入组名额者沿用available-case + consumed-slot原则。具体样本量、Stage1信息比例、CP阈值和情景Operating Characteristics将在相关统计设计文件中确定，且不构成确认性有效性假设检验。

**目前最后决策建议：** 不直接把N50/臂等新数字写入CP正式版本；本版先供统计团队评估。**历史假设30% vs 20%/15%已找回，历史独立最终样本量未查实。**
