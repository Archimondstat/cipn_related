## 2. 同类型研究及官方规则（明确其证据用途）

| 依据 | 可直接支持的事实 | 适用边界 |
|---|---|---|
| **FACIT官方评分规则**, https://www.facit.org/scoring | 单个FACIT subscale：**超过50%条目完成**才允许prorating；先按官方题目方向reverse score，再用已回答项均值乘该subscale总题数，计分可与无缺失时同范围；其**整体量表总分>80%**要求不同于单个subscale | 本试验分析的是11项**Ntx subscale**，不能把完整FACT-G/FACT总分的80%完成门槛搬来；医学仍需核对授权中文v4问卷和计分模板 |
| **GOG成人肿瘤随机III期试验**, https://pmc.ncbi.nlm.nih.gov/articles/PMC4459781/ | 治疗组间分析使用FACT/GOG-Ntx subscale **0–44**，文中明确当**多于50%但不足100%条目完成**时按比例校正 | 肿瘤/背景治疗不同，但是真实成人多中心随机临床试验中应用同一11项神经毒性subscale及门槛的先例 |
| **COG AHOD1331**, Parsons等, *J Patient Rep Outcomes* 2023，https://link.springer.com/article/10.1186/s41687-023-00653-0 | 11-item FACT/GOG-Ntx，0–44高分好；Methods明确至少半数题目有效才计算（50% rule） | 儿童/霍奇金淋巴瘤，不是与AK135相同人群；用于佐证具体FACT-Ntx11计分与缺失门槛，并非本试验临床终点事件先例 |
| **ECOG-ACRIN E2511**, *Cancer Medicine* 2020, https://onlinelibrary.wiley.com/doi/full/10.1002/cam4.3416 | FACT神经毒性量表得分越低症状越严重；条目缺失**少于50%**者可prorate，缺失达到或超过50%者为missing | 成人肿瘤随机II期中采用同类缺失处理；原发表方法与本研究不同，不移植其其他终点 |
| **FACT-G个别条目非应答方法学**, https://pubmed.ncbi.nlm.nih.gov/8763800/ | 在已答>50%时以该subscale已答项均值填补/比例校正，和剔除整例相比通常更少偏差 | 早期FACT-G方法学而非直接针对Ntx11，作为补充理由 |

**一致结论：** 对11项量表“回答超过50%”等价于**至少6/11项有效回答**；5/11不足，不计算。11为奇数，COG原文“至少一半”和FACIT“严格超过一半”在实际最少整数门槛上同为6项。

## 3. 建议的研究专属规则（需用户确认）

1. **每次FACT-Ntx11有效问卷**：11项中至少6项有效回答（原始题值0/1/2/3/4，按正式授权模板进行反向计分后范围仍为0–4）；回答数`m>=6`时才计算11项分量表；`m<6`为missing。
2. **Prorating**：`Ntx11 = 11 * sum(valid reverse-scored item values) / m`，`m`为11项中的有效回答数；0–44，高分好。完整11项时即反向计分后直接求和。缺失条目不按0填入，也不将本评分再转换成0–100。
3. **指定访视恶化>12**：仅当基线与当前指定访视评分均有效时计算`Baseline_Ntx11−Visit_Ntx11>12`；否则该访视的恶化标识为**indeterminate/missing**，不可自动当作未恶化或恶化。
4. **分析分母**：FACT恶化比例为**可获得有效基线和该访视FACT-Ntx11评分的人数**。按治疗组/访视报告随机或对应分析集总N、有效评分人数、恶化人数和有效率/缺失率，并描述缺失主要原因；不把未完成问卷的受试者直接排除出全研究分析集。
5. **部分条目缺失 vs 整个访视缺失**：上述prorating只处理**问卷内部部分条目缺失**；如果整次访视没有FACT数据，则没有可prorate的条目，不自动做LOCF、BOCF或用CTCAE/CIPN20补FACT。研究仅描述性II期，必要时做完整11项问卷者支持性描述，评估prorating对>12分类的影响，是否实施取决于最终SAP。
6. **分类阈值**：严格保留CP-11已有`>12`，而非`>=12`。缺失校正结果可能有小数，建议在不预先四舍五入的原始精度上判阈值，表格展示精度另由SAP规定。
7. **范围边界**：按**11项Ntx subscale**的6/11计分，不用完整FACT-G(27项)的>80%答题规则；如果医学最终确认不同的量表版本，则在更新分母条目总数、范围和具体score manual之后才实施，不能默认11项公式适用13项。
