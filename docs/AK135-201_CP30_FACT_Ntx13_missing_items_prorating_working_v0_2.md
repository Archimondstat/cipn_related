**术语澄清：** FACIT官网的FACT/GOG-NTX-13 v4是**完整40项问卷（27项FACT-G+13项Ntx）**；本统计终点只指其13项Ntx subscale，能否仅发给患者13项独立问卷应与医学/授权和实际CRF/eCOA核对。不可将完整40项的有效性要求套用到13项subscale。

## 2. 一手依据与同类型研究

1. **FACIT官方13项版本**：https://www.facit.org/measures/fact-gog-ntx-13 。确认版本4，完整问卷40题（27+13），过去7日、原始0–4每项，官方评分manual及部分reverse score，13-item Ntx。两个新增问题针对冷刺激相关神经毒性，最初主要为奥沙利铂背景开发；混合药物背景应注意研究组间适用性，但不能自行删除2项。
2. **FACIT官方计分与缺失规则**：https://www.facit.org/scoring 。独立subscale须有**超过50%**的有效回答才能prorating，不同于完整FACT问卷总分的>80%要求；`13*0.5=6.5`，故13项最少有效**7项**。反向计分必须按正式template逐条执行（不是擅自把所有题统一倒置）。
3. **同类CIPN预防药研究POLAR-A/M**：https://cdn.clinicaltrials.gov/large-docs/55/NCT04034355/Prot_000.pdf ，Protocol§8.1.1.1明确FACT/GOG-NTX-13 v4原始问卷13条及量表范围0–52；其主要事件以**前4题原始症状0–4**评定，**不是用标准Ntx13反向总分较基线下降>12**，故只能借鉴问卷选择与定义，不应照搬主结局。
4. **NOVIT 2025队列研究**：https://link.springer.com/article/10.1007/s00520-025-09282-3 。使用FACT/GOG-Ntx13 v4，27项FACT-G +13项神经毒性分量表，按评分手册总分范围0–160，其中Ntx 0–52，高分好；其分析界值为**相对基线下降≥10%**，非本研究>12。
5. **CIPN PRO systematic review 2022**：https://pmc.ncbi.nlm.nih.gov/articles/PMC9546984/ 。指出FACT-Ntx13是在11项基础上**增加两项冷诱发症状**；标准FACIT计分高分代表更好，不与未反向的原始症状负担总分混淆。
6. **FACIT官方13项评分文档入口**：https://www.facit.org/measures-scoring-downloads/fact-gog-ntx-13-scoring-downloads 。在SAP定稿前从授权版本核实所有条目、翻译、反向条目与缺失代码。

## 3. 缺失处理规则及具体算法：建议采用，尚待用户确认

- 每次指定访视13个条目中，**至少7项有效作答**，才能计算FACT-Ntx13 subscale，记有效计分条目数为`m`。
- 按正式FACIT manual对每个有效条目进行应有的reverse scoring得到`s_i∈{0,1,2,3,4}`，则：
  `Ntx13_score = 13*(sum_{i in answered} s_i)/m`, `m>=7`；范围0–52，高分更好。
- `m<=6`时整次Ntx13评分缺失；已回答条目求和不能未经prorating拿来与满13项得分比较，未回答条目也不能赋0。
- 若医学维持原CP探索性次要界值“FACT/GOG-Ntx较基线恶化>12”，且确认标准FACIT反向计分，则`Worsening = Baseline_Ntx13 − Visit_Ntx13 >12`。仅当**基线与指定访视两次均有效评分**才能判定；否则该二分类状态**indeterminate/missing**，不自动视为未恶化。
- 各访视报告FACT可评价分母、原评分与较基线变化，必要时按完整13项/部分7–12项/无法计分0–6项区分，关注不同队列和治疗组缺失分布。
- Prorating只是问卷内部缺失计分，不是对整个访视未观察到的FACT评分做插补，不用LOCF、CTCAE、CIPN20自动补值。
- 判定`>12`用未四舍五入的得分差；展示的小数位另由SAP规定。
- 冷刺激条目属于13项的组成部分，即使BC非奥沙利铂队列，也不能因医学上认为不常见而自行当缺失/不适用或删除；评估其临床含义属于医学/量表团队。

## 4. Protocol §11.5.2最简建议写法

> FACT/GOG-Ntx采用13项神经毒性分量表（FACT-Ntx13）进行评价，每次评价至少需有13项中的7项有效回答方可计算评分；存在部分条目缺失时，按照FACIT评分规则进行比例校正。具体条目编码、反向计分、缺失处理、评价访视及分析分母的衍生规则将在SAP中规定。

如果CP描述>12恶化比例，沿用已定探索性定义时必须写明反向分的下降方向；但建议核实“>12”在0–52的Ntx13分量表上是否有直接可追溯的阈值来源。**这不是要用户重新确认已选择的13项量表，而是阈值解释的证据限制。**
